# Annotation provenance

This experiment uses only the category ontology and structured annotations from
[Fashionpedia](https://github.com/cvdfoundation/fashionpedia). The Fashionpedia
Consortium licenses annotations and ontology under
[Creative Commons Attribution 4.0](https://fashionpedia.github.io/home/data_license.html).
Credit: Menglin Jia et al., *Fashionpedia: Ontology, Segmentation, and an Attribute
Localization Dataset*, ECCV 2020, https://arxiv.org/abs/2004.12276.

No images are downloaded or redistributed. Image copyright is separate and is
not covered by the annotation license. Original image URLs are used locally only
to derive a source-group digest for duplicate/leakage checks, never as model inputs
or published report fields. Raw annotations remain in an ignored external cache;
published artifacts contain aggregates, opaque group digests and category IDs.

This package is a new task construction and experiment using existing annotations;
it is not an official Fashionpedia benchmark, reproduction of its vision task,
or a claim about human clothing preferences.
